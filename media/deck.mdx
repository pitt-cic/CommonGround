<Slide tab="problem">

# The Problem

- **High-impact research** never reaches the broader audiences who need it most


- **Dense academic language** excludes non-specialists


- **Scientists lack time** to translate their own findings

</Slide>

<Slide tab="solution">

# The Solution



Finding the **CommonGround** betweeen researchers and various audiences

- A web app that translates complex research papers to the output of your choice 
- Tailored to set and custom audiences

Outputs: summaries, press releases, blog posts, LinkedIn posts, infographics

</Slide>

<Slide tab="architecture">

# High Level Architecture



```
Browser → API Gateway → Lambda → Bedrock (Claude)
              ↓               ↓
           Cognito         DynamoDB (state)
              ↓               ↓
             S3 ← PDFs    S3 ← Infographic assets
```

- **CDK** IaC(Infrastructure as Code)
- **Serverless** (pay per use)
- Solution on **Github** for more technical details

</Slide>

<Slide tab="pricing">

# Pricing Breakdown

**Estimated workload: 3-4 papers / month per org or department**

| | Rate | Monthly cost |
|---|---|---|
| **Hosting** — one shared deployment | fixed | ~$10-20 |
| **Paper processing** — generation + 10 refinements + 5 infographics | ~$2 / paper | ~$6-8 |
| **Total** | | **~$20-30** |

Cost scales **linearly** with papers processed, not with number of users.

</Slide>
